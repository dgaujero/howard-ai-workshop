## Setup

Use a [Node.js version supported by Angular 21](https://angular.dev/reference/versions) (20.19+, 22.12+, or 24.x) and npm. This project was initialized with Node.js 20.20.2 and npm 10.8.2.

Install the locked dependencies:

```bash
npm ci
```

The commands below use the project's local Angular CLI; no global installation is required.

## Development server

To start a local development server, run:

```bash
npm start
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
