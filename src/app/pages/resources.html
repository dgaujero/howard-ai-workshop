Set up Codex in VS Code

  1. Open your project folder in VS Code.
  2. Use the official Codex IDE guide to install the extension and sign in.
  3. Review the permissions and scope before allowing edits or commands.
  4. Begin with the “Understand a repo” prompt, then open the files it cites.

Follow the engineering loop

GitHub + Vercel setup

  1. Review the code, run the tests and production build, then commit the intended changes to GitHub.
  2. Import the repository into a Vercel project. Confirm the project root and production branch.
  3. For this starter, build from the repository root with npm run build and publish dist/howard-ai-workshop/browser.
  4. Match the deployment’s commit to the one you pushed. Open its URL and check navigation, guide content, and any features added during class.
  5. Check the exact shared URL while signed out. Localhost is only available on your machine.
