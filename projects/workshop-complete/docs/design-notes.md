# Design direction and resource sources

## Theme

The completed guide uses a spacious reading layout, dominant navy, limited red accents, an editorial heading hierarchy, and a shared set of CSS values in `src/styles.css`.

Howard’s [published color reference](https://finearts.howard.edu/colors-typography) lists blue `#003A63` and red `#E51937`. These inform the guest-lecture resource’s palette. Guest-lecture attribution is visible in the header and footer; the app does not use a university seal or claim to be an official university service.

Georgia headings, system body fonts, monospace labels, spacing, cards, and the layout are choices made for this implementation. They are not claims about fonts or interactions identified from screenshots. No presenter reference screenshots were supplied with the script, and no screenshot analysis has been presented as if those images were available.

Suggested sources for the presenter’s actual screenshot capture:

- [Howard University homepage](https://howard.edu/)
- [Howard Fine Arts color and typography reference](https://finearts.howard.edu/colors-typography)

Capture desktop and narrow layouts, retain URLs and capture dates, and label any saved analysis as rehearsal material.
