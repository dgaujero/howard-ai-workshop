Two ways to get started

With an agent

Set up Codex in VS Code

  1. Open your project folder in VS Code.
  2. Use the official Codex IDE guide to install the extension and sign in.
  3. Review the permissions and scope before allowing edits or commands.
  4. Begin with the “Understand a repo” prompt, then open the files it cites.
Official IDE setup ↗

Without agent access

Use the process with what you have

Read the guides here for free. If your course permits it, use a chat tool you already have access to, provide relevant non-private context, and run the checks yourself.

Access to a coding agent is not required to practice reading code, planning a change, reviewing a diff, or testing a result.

From a commit to a live URL

GitHub + Vercel setup

  1. Review the code, run the tests and production build, then commit the intended changes to GitHub.
  2. Import the repository into a Vercel project. Confirm the project root, build command, output directory, and production branch.
  3. For this completed Field Guide, use npm run build:complete and dist/workshop-complete/browser from the repository root.
  4. Match the deployment’s commit to the one you pushed. Open its URL and test selection, copying, and navigation.
  5. Check the exact shared URL while signed out. A protected preview or localhost URL is not a public classroom resource.
